# 知识库

知识库是一个**静态资料库**插件：资料由用户自行整理、分区存放，插件负责把它们变成模型可读、可检索的文件，并在对话中按「资料库优先」的规则使用。

## 能做什么

- **自定义分区**：一个资料库就是一类书，例如「毛泽东选集资料库」「公司制度库」。左栏一行一个资料库，随时新建、改名、删除。
- **导入与转化**：支持上传 PDF、HTML、Markdown、TXT、EPUB、DOCX 等文件，粘贴网页正文，或直接填网址抓取公网页面。导入后由模型把原文转化为结构化的 Markdown（保留章节、生成摘要与标签），转化完成的文档才能被检索。
- **绑定到对话**：每个对话标题栏都有一个资料库控件：未绑定时显示「绑定」，点开后在面板里点一下资料库即可；已绑定则显示资料库名与可检索篇数。绑定后，模型先查资料库再回答；资料库与网络/模型知识出现小歧义时以资料库为准，出现关键冲突时会立刻停下来询问你。
- **文件面板**：侧边栏导航里的「资料库」是独立主面板（和「上下文洞察」「邮件」同级）。左栏是资料库列表，右上方按文件类型（PDF / HTML / Markdown / 文本 / 其他）切换，正区列出该类型的文件；双击文件即可在 Harness 内预览。

## 怎么用

1. 点侧边栏导航里的「资料库」打开主面板，新建一个资料库。
2. 在面板里上传文件、粘贴文本或填网址抓取；等待状态从「待转化」变成「可检索」，也可以点「AI 转化」立即处理。
3. 在任意对话的标题栏点「绑定」，在面板里点一下要绑定的资料库（再点一次控件可换库）。
4. 直接提问即可。模型会用 `kb_search` 检索资料库、用 `kb_read` 读原文，并按绑定规则回答。

## 边界

- 资料保存在本机 `$DSH_HOME/knowledge-base/`，是用户可读的普通文件（`library.json` + 每个资料库目录下的 `raw/`、`text/`、`docs/`），不进 Git、不上传。
- 扫描版 PDF、加密 PDF、MOBI/AZW3 等格式无法直接抽取文字，会停留在「待转化」；此时可在对话里让模型用 PDF 阅读工具读入并写回资料库。
- 自动转换使用当前默认模型；模型未配置或调用失败时，文档会保留原文并提示改用对话内的工具转化。
