# 知识库

知识库是一个**静态资料库**插件：资料由用户自行整理、分区存放，插件负责把它们变成模型可读、可检索的文件，并在对话中按「资料库优先」的规则使用。

## 能做什么

- **自定义分区**：一个资料库就是一类书，例如「毛泽东选集资料库」「公司制度库」。左栏一行一个资料库，随时新建、改名、删除。
- **导入与转化**：支持上传、拖入右侧文件区、粘贴网页正文，或直接填网址抓取公网页面（PDF、HTML、Markdown、TXT、EPUB、DOCX 等）。导入后由模型把原文转化为结构化的 Markdown（保留章节、生成摘要与标签），转化完成的文档才能被检索。
- **可单独配置转化模型**：面板左上角齿轮可配置 OpenAI 兼容的服务地址、文本模型、视觉模型与 API Key，方便用更便宜的模型；API Key 存在 DSH 凭据里，不写入配置文件。
- **资料库级全量转化**：资料库名称右边的「全量转化」会把未转化与部分转化的文档一次跑完，已转完的跳过。
- **视觉兜底与复核**：抽取失败、文本质量差或图片文档会把 PDF 整页渲染后交给视觉模型转写；转化后可再用视觉抽样复核，问题显示在文档行上，并可用「修复」按复核意见重转、再复核。
- **文本太差可直接改用视觉**：抽取质量低或只剩残片时，文档行提供「用视觉提取」（未转化）或「视觉重建」（已用文本转过）。
- **疑似残缺可整篇视觉重做**：OCR 残片、摘要自述缺失等不可靠结果，会给出「视觉全量转化」，逐页识别并覆盖原文。
- **页数进度与继续转化**：视觉只读取前 N 页时会在文档行注明，并提供「继续转化」（再跑一批）与「全量转化」（剩余页面一次跑完）；转化过程中显示进度条、阶段、百分比与已用时间，标题栏显示「转化中 N 篇」。
- **并行转化**：文本分段与视觉批次默认 3 路并发，可在「转化设置」里调整（1–6）；页面渲染精度也可调低以减小图片体积。
- **绑定到对话**：每个对话标题栏都有一个资料库控件：未绑定时显示「绑定」，点开是一个贴着按钮的小列表，选一下即绑定、不离开对话；已绑定则显示资料库名与可检索篇数，再点可换库或解绑。绑定后，模型先查资料库再回答；资料库与网络/模型知识出现小歧义时以资料库为准，出现关键冲突时会立刻停下来询问你。
- **文件面板**：侧边栏导航里的「资料库」是独立主面板（和「上下文洞察」「邮件」同级）。左栏是资料库列表，右上方按文件类型（PDF / HTML / Markdown / 文本 / Word / Excel / PPT / 图片 / 其他）切换，正区列出该类型的文件；双击文件即可在 Harness 内预览。

## 怎么用

1. 点侧边栏导航里的「资料库」打开主面板，新建一个资料库。
2. 在面板里上传文件、粘贴文本或填网址抓取；等待状态从「待转化」变成「可检索」，也可以点「AI 转化」立即处理。
3. 在任意对话的标题栏点「绑定」，在弹出的列表里选要绑定的资料库（不离开对话）；要整理资料时点「管理资料库」进入侧边栏的资料库主面板。
4. 直接提问即可。模型会用 `kb_search` 检索资料库、用 `kb_read` 读原文，并按绑定规则回答。

## 边界

- 资料保存在本机 `$DSH_HOME/knowledge-base/`，是用户可读的普通文件（`library.json` + 每个资料库目录下的 `raw/`、`text/`、`docs/`），不进 Git、不上传。转化文件命名为「模型总结的标题（原文件名）.md」。
- 扫描版（纯图片）PDF、加密 PDF、MOBI/AZW3 等格式需要 OCR 或视觉模型；配置视觉后可自动尝试，纯矢量且没有内嵌页面图的 PDF 仍需对话内读图或外部 OCR。
- 视觉转化与复核会产生额外模型调用与费用，可在设置里关闭。
- 大文档用当前默认模型转化可能耗时数分钟；任务在后台运行，可以关闭面板，进度与失败原因会显示在文档行上。
- 自动转换使用当前默认模型；模型未配置或调用失败时，文档会保留原文并提示改用对话内的工具转化。
